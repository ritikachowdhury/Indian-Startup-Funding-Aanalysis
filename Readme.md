#### **Indian Startups Funding Analysis** 



**Project Overview**



This project analyzes funding trends in the Indian startup ecosystem using Power BI. The dashboard provides insights into startup funding patterns across industries, cities, investment types, and time periods.



**Objective**



The objective of this project is to identify:



\* Top funded industries

\* Leading startup hubs

\* Most funded startups

\* Dominant investment types

\* Funding trends over time



**Tools Used**



\* Power BI

\* Microsoft Excel

\* Power Query

\* DAX



**Dashboard Features**



\* KPI Cards



&#x20; \* Total Funding

&#x20; \* Total Startups

&#x20; \* Total Cities

&#x20; \* Total Industries



\* Industry-wise Funding Analysis



\* City-wise Funding Distribution



\* Top 10 Funded Startups



\* Investment Type Funding Distribution



\* Funding Trend Over The Years



\* Interactive Slicers



**Data Cleaning**



\* Handled missing values

\* Standardized city names

\* Cleaned funding amount formats

\* Removed inconsistencies in categorical fields

\* Created DAX measures for KPI calculations



**Key Insights**



\* Ecommerce attracted the highest funding among industries.

\* Bengaluru emerged as the leading startup hub.

\* Private Equity dominated investment activity.

\* Flipkart secured the highest funding among startups.

\* Startup funding peaked significantly during 2019.
